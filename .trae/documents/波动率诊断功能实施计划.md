# 波动率诊断功能实施计划

## Context（背景）

用户要求在 `盯盘工具/src/pages/stock_diagnosis` 下新增一个一级 tab「波动率诊断」，下设两个二级 tab：
1. **个股诊断**：仿照买卖点诊断（BacktestDiagnosisTab），支持选股 + 选择时间段（默认最近 20 天），对每个交易日基于当日 1 分钟分时数据（涨幅、成交量）计算全天波动率总值，并将波动率折线叠加绘制在该股 K 线图上。
2. **多股诊断**：对全部自选股按今日分时数据全量计算波动率，列表展示，支持按波动率高低排序。

波动率算法需采用业界前沿量化方法，综合 1 分钟涨幅与成交量信息，给出单日波动率总值。

## 波动率算法设计（体积加权跳跃稳健已实现波动率）

综合三篇现代金融计量经典方法：

1. **已实现波动率 RV**（Andersen, Bollerslev, Diebold & Labys, 2003）：基于高频 1 分钟对数收益率的平方和，非参数、模型无关的积分方差估计。
2. **双幂变差 BPV**（Barndorff-Nielsen & Shephard, 2004）：用相邻收益乘积（π/2）Σ|r_t||r_{t-1}|，跳跃稳健——孤立的大幅跳动不会膨胀该估计，从而可分离跳跃成分。
3. **成交量加权 RV**：用每分钟相对成交量份额 w_t = v_t / Σv 加权各平方收益，强调高成交时段的价格信息含量。

**计算流程**（输入：单日分时 line 数组，字段含 minute / last_px / business_amount）：

```
1. 过滤有效交易分钟（0930–1130、1300–1500），要求 last_px > 0
2. 计算 1 分钟对数收益率 r_t = ln(p_t / p_{t-1})，及对应区间成交量 v_t
3. 成交量权重 w_t = v_t / Σv
4. 成交量加权已实现方差 RV_vw = N · Σ(w_t · r_t²)   （N 为收益个数，等权时退化为标准 RV）
5. 双幂变差 BPV = (π/2) · Σ_{t≥2} |r_t| · |r_{t-1}|   （跳跃稳健连续方差）
6. 跳跃方差 JumpVar = max(RV_vw − BPV, 0)
7. 连续方差 C = BPV
8. 最终日波动率方差 = C + 0.5 · JumpVar   （跳跃部分折半计入，因其非持续性）
9. 日波动率总分 volScore = √(C + 0.5·JumpVar) × 100   （百分比形式，便于横向比较）
```

输出结构（每日）：
- `volScore`：日波动率总分（%，折线绘制用此值）
- `realizedVol`：未加权已实现波动率（%）
- `volumeWeightedRV`：成交量加权已实现波动率（%）
- `bipowerVol`：连续（跳跃稳健）波动率（%）
- `jumpRatio`：跳跃占比 = JumpVar / RV_vw
- `tradeDate`、`minuteCount`（有效分钟数）

## 实施步骤

### 一、后端

#### 1. 新建 `server/src/service/volatilityDiagnose.js`

核心函数：

- `calculateDailyVolatility(line)` — 上述算法实现，返回波动率指标对象；line 无效或点数不足返回 null。
- `diagnoseSingleStockVolatility(code, startDate, endDate)` — 个股多日诊断：
  - 调用 `getSingleStockData(code, 100)`（来自 `./stock`）取 K 线，仿 buySellDiagnose `backtestSingleStock`；
  - 按 startDate/endDate 过滤交易日；
  - 批量并行拉取各日分时 `getSingleStockTlineDataByDate(code, tradeDate)`，BATCH_SIZE=5、批次间 sleep(200)；
  - 对每日 line 调 `calculateDailyVolatility`，将 `volatilityScore` 挂到对应 K 线点上；
  - 返回 `{ success, data: { code, stockName, klineData, volatilitySeries: [{time, value: volScore, ...metrics}], summary } }`。
- `diagnoseMultiStockVolatility()` — 多股今日诊断：
  - `getMonitorStocks()`（来自 `./monitorStock`）取全部自选股；
  - `batchParallel` 并发（useCLS ? 3 : 10）对每只股票调 `getSingleStockTlineData(code)`（当日分时，无 date 参数）；
  - 计算每只波动率，附带当日 change（从 stockData.json 缓存或分时末点）；
  - 返回 `{ success, data: [{ code, stockName, change, volScore, realizedVol, jumpRatio, minuteCount, error? }] }`。

依赖引入（仿 buySellDiagnose.js）：
```js
const { getSingleStockData, getSingleStockTlineData, getSingleStockTlineDataByDate } = require('./stock');
const { getMonitorStocks } = require('./monitorStock');
const { batchParallel, sleep } = require('../utils');
const { useCLS } = require('../config');
```

#### 2. 在 `server/src/index.js` 注册路由与导入

- 顶部 import 区加入 `const { diagnoseSingleStockVolatility, diagnoseMultiStockVolatility } = require('./service/volatilityDiagnose');`
- 路由区加入：
  - `POST /volatility_diagnosis`（body: `{ code, startDate, endDate }`）→ `diagnoseSingleStockVolatility`
  - `GET /volatility_multi_diagnosis` → `diagnoseMultiStockVolatility`

- 依赖数组 `[data, volatilityData, height]`；`handleScroll/handleScale: false`（遵守项目约束）。

#### 4. 新建 `VolatilitySingleDiagnosisTab.jsx`（个股诊断子 tab）

仿 `BacktestDiagnosisTab.jsx` 结构：
- 状态：`stockList`（从 `/buy_sell_selectable_stocks` 拉取，复用现有接口）、`selectedRowKeys`、`dateRange`（默认 `[dayjs().subtract(20,'day'), dayjs()]`）、`diagnosing`、`result`、`error`；

- 结果渲染：`VolatilityKLineChart`（传入 klineData + volatilitySeries）+ 波动率明细表（日期 / volScore / 连续波动 / 跳跃占比 / 有效分钟数，支持排序）+ 算法说明 Alert；

## 验证方式

1. 重启后端服务（`server/src/index.js` 改动需重启生效）。
2. 前端 dev 环境打开个股诊断页 → 选择一只股票 → 默认 20 天 → 点击开始诊断：
   - 验证 K 线图渲染 + 青色波动率折线叠加在右侧独立坐标轴；
   - 验证明细表列出每日 volScore 及各分项；
   - 验证 tooltip 显示波动率行。
3. 切换到多股诊断 tab → 自动加载列表 → 验证按 volScore 升序/降序排序正常。
4. 边界：分时数据不足的股票/日期应显示「数据不足」而非报错。
5. 性能：多股诊断并发数受 `useCLS ? 3 : 10` 控制，不应对数据源造成过大压力。
