# 「攻防兼备」模式实盘上线实施计划

## Context

把回测中的融合策略「科技进攻-情绪游资极致胜率」（`sci_attack_emo_win`，引擎 `runFusedEmoWinBacktest`）搬到线上实盘：在开盘实战页模式切换中新增第三个模式「攻防兼备（attack_defense）」，双策略（科技进攻/快进快出 + 情绪游资-极致胜率顺/逆周期）同时做买/卖点诊断并各自展示；卖点按持仓股是否属于自选股科技股范围分流诊断方式；股票列表分三段；后端轮询任一命中即推飞书；所有模式（含原有两种）的飞书消息、买点抽屉、买点弹窗增加与回测一致的仓位提示。

## 仓位提示口径（与回测完全一致，来源 fusedEmoWinBacktest.js）

- **科技进攻（A 风格）**：当日为快进快出日（`checkEmoQuickOutDay(today).quickOut===true`）→ 首次买入**半仓 50%**，次日买点再次触发且未涨停时补足第二份半仓 50%，该笔次日 10:00 强卖；普通买入日 → **全仓 100%**
- **情绪游资（B 风格）**：双腿结构，顺周期腿、逆周期腿各**半仓 50%**（LEG_WEIGHT=0.5）
- **优先级（攻防兼备）**：两策略同时触发时快进快出优先；某风格建仓后另一风格须等本笔结束（实盘仅提示，不做锁状态机）
