# 训练营回放页面实现方案

## Context（背景）

用户希望新增一个"训练营"页面，基于 `amountSnapshot`（10min 成交量快照）和 `fundSnapshot`（5min 主力资金快照）的历史数据，对某一天的盘面进行分时间桶（5min）的逐桶回放。回放内容复用盯盘页面的多个模块（个股异动、分区/合并tab、叠加分时、涨跌幅前十、主力资金/成交量折线图），并在最右侧展示策略中心的策略回测卡片，命中策略时弹出提示。底部吸底播放进度条支持拖拽、快进/倒推、暂停。

**数据缺口已澄清**：
- 涨跌幅前十 → 从自选股历史分时数据（`getSingleStockTlineDataByDate`）按回放时间桶实时计算，而非板块维度
- 分区/合并tab 资金净流入字段不展示（仅保留股票名称+涨跌幅）
- 叠加分时 → 改造 `MultiStockTimeLineModal` 支持历史数据注入
- 日期分组 → 存后端文件 `server/src/data/training_camp_groups.json`

## 后端改动

### 1. 新增服务 `server/src/service/trainingCamp.js`

**核心函数**：

- `getTrainingCampDates()` — 复用 `strategyBacktest.js` 的 `getAvailableDates()`，返回 `amountSnapshot`/`fundSnapshot` 目录下所有日期（降序）
- `loadTrainingCampData(dateStr)` — 一次性加载某日期全部回放数据，返回统一时间桶结构
- `getTrainingCampGroups()` / `saveTrainingCampGroup(group)` / `deleteTrainingCampGroup(id)` — 分组 CRUD，读写 `server/src/data/training_camp_groups.json`

**`loadTrainingCampData` 返回结构**（关键）：

```js
{
  date: '20260821',
  dateDisplay: '2026-08-21',
  monitorStocks: [{ code, name }, ...],   // 自选股列表
  indexKline: { cyb, kcb },               // 指数日K线（静态）
  strategies: [...],                       // 策略定义列表
  timeBuckets: [                           // 5分钟时间桶数组（时钟）
    {
      timeKey: '093500',                  // HHmmss
      displayTime: '09:35',
      fundFlow: 12.3,                     // 当桶主力资金净流入(亿)
      volume: 45.6,                       // 当桶成交量增量(亿)
      indexTline: {                       // 当桶指数分时点
        cyb: { price, changePct },
        kcb: { price, changePct }
      },
      stockChanges: [                     // 当桶自选股涨跌幅快照
        { code, name, changePct, lastPx }, ...
      ],
      signals: [                          // 当桶命中的策略信号
        { strategyId, title, description, isBullish }
      ]
    }, ...
  ]
}
```

**时间桶对齐逻辑**（以 fundSnapshot 5min 为基准时钟）：
- fundSnapshot 每个点 → 一个时间桶，`fundFlow` = `mainMoney`
- amountSnapshot 10min → 对齐到最近的5min桶，`volume` = `amountChangeDiff`
- 指数分时 → 取桶时间点对应的分时点（`getIndexTlineByDate` 返回的 line）
- 自选股分时 → 遍历 `getMonitorStocks()`，对每只调用 `getSingleStockTlineDataByDate(code, date)`，取桶时间点的 `last_px`，计算 `changePct = (last_px - preclose_px)/preclose_px * 100`
- 策略 signals → 复用 `runBacktest(date)` 返回的 `signals`，按 `timeKey` 分配到对应桶

**复用的现有函数**（路径）：
- `getAvailableDates`、`loadSnapshotData` — `server/src/service/strategyBacktest.js`
- `getIndexTlineByDate` — `server/src/service/fupan.js`
- `getAllIndexKlineData` — `server/src/service/emotion.js`
- `getMonitorStocks` — `server/src/service/monitorStock.js`
- `getSingleStockTlineDataByDate` — `server/src/service/stock.js`
- `runBacktest` — `server/src/service/strategyBacktest.js`（只取 signals + strategies）

**分组文件结构** `server/src/data/training_camp_groups.json`：
```json
[
  { "id": "g1", "name": "情绪冰点周", "dates": ["20260818","20260819","20260820"] }
]
```

### 2. 新增路由（`server/src/index.js`，仿照现有 `/backtest/*` 风格）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/training_camp/dates` | 可回放日期列表 |
| GET | `/training_camp/data?date=YYYYMMDD` | 某日期全量回放数据 |
| GET | `/training_camp/groups` | 分组列表 |
| POST | `/training_camp/groups` | 新增/更新分组（body: `{id?, name, dates}`） |
| DELETE | `/training_camp/groups/:id` | 删除分组 |

## 前端改动

### 1. 路由与菜单

- `盯盘工具/src/router.jsx` — 在主布局子路由新增 `{ path: 'training_camp', element: <TrainingCamp /> }`
- `盯盘工具/src/App.jsx` — `menuItems` 数组仿照现有格式新增一项（key=`/training_camp`，label=`训练营`，选合适 icon）

### 2. 新增页面 `盯盘工具/src/pages/trainingCamp/`

**目录结构**：
```
src/pages/trainingCamp/
  index.jsx              # 页面主入口，状态管理 + 布局
  index.scss
  utils/
    useReplay.js         # 回放状态机 hook
  components/
    TopBar/              # 日期选择 + 分组选择
    ReplayProgressBar/  # 底部吸底进度条
    StrategySidePanel/   # 右侧策略回测面板
```

**`index.jsx` 核心逻辑**：
1. 挂载时拉取 `/training_camp/dates` 和 `/training_camp/groups`
2. 选择日期后拉取 `/training_camp/data?date=`，得到 `timeBuckets`
3. `useReplay(timeBuckets)` 管理回放状态：`currentIndex`、`isPlaying`、`play/pause/seek/stepForward/stepBackward`
4. 播放时 `setInterval(5000)` 推进 `currentIndex`，到末桶自动暂停
5. 当前桶数据 → 注入到各子组件

**`useReplay` hook（`utils/useReplay.js`）**：
```js
const { currentIndex, currentBucket, isPlaying, progress,
        play, pause, toggle, seek(index), stepForward, stepBackward }
  = useReplay(timeBuckets, { autoPlay: false, intervalMs: 5000 });
```

### 3. 左侧主区组件接入（复用 dingpan 组件，注入历史数据）

| 训练营模块 | 复用组件 | 数据注入方式 |
|-----------|---------|-------------|
| 主力资金+成交量折线图 | `dingpan/components/MainMoneyCharts` | `historyData` 传当前桶及之前累计的资金/成交量序列；`moneyStatus`/`volumeStatus` 由当前桶计算趋势 |
| 涨跌幅前十（自选股） | `dingpan/components/BlockRankingCards`（复用，传入构造的 `topAndBottomBlockData`） | 从 `currentBucket.stockChanges` 排序，涨幅前5+跌幅前5，组装成 `{firstNumList, lastNumList}` 喂给组件 |
| 个股异动 | `dingpan/components/StockAlertCard` | `stockUpAlerts`/`stockDownAlerts` 从当前桶涨跌幅超阈值个股计算；`waveList` 置空 |
| 分区/合并tab | `dingpan/components/StockChangeMonitor` | `stockData` 注入当前桶个股；`stockViewMode` 仅保留 `grouped`/`merged`/`statistics`（去掉 `research`）；**删除 fundText 渲染**（约第60行 `<span className="stock-change-fund">` 整块） |
| 叠加分时 | `components/MultiStockTimeLineModal`（改造） | 新增 `replayMode` + `replayStocks` + `replayCurrentTimeKey` props，详见下节 |

**MainMoneyCharts 适配说明**：该组件原本接收轮询的 `historyData`（最近15分钟资金序列）。训练营中，传入"从开盘到当前桶"的累计资金/成交量序列，图表展示当日截止当前桶的资金流和成交量趋势。组件内部 `lightweight-charts` 的 `handleScroll`/`handleScale` 保持 `false`（项目硬约束）。

**StockChangeMonitor 改造**：为避免影响原 dingpan 页面，通过新增可选 prop `hideFundFlow`（默认 false）控制是否渲染资金净流入 `<span>`，训练营传 `true`；通过 `viewModes` prop 控制显示哪些 tab 按钮，训练营传 `['grouped','merged','statistics']`。

### 4. 改造 `MultiStockTimeLineModal` 支持历史回放

新增可选 props：
- `replayMode: boolean` — true 时禁用轮询与 localStorage 持久化
- `replayStocks: [{code, stockName, tlinePoints: [{minute, last_px}]}]` — 预加载的历史分时数据
- `replayCurrentTimeKey: string` — 当前回放时间桶 timeKey（HHmmss），组件内按此截断展示

内部改动：
- `useEffect` 中 `if (replayMode) { 用 replayStocks + replayCurrentTimeKey 截断生成 chartData; return; }` 提前返回，跳过原有 `fetchTlineData` 轮询
- 图表渲染逻辑复用，只到 `replayCurrentTimeKey` 之前的分时点
- "批量添加"按钮在 replayMode 下禁用（历史数据无法动态追加新股票，需先选好股票再开始回放）

### 5. 右侧策略回测面板 `StrategySidePanel`

- 复用 `strategy_center` 的策略卡片样式（利好绿底/利空红底，项目硬约束）
- 展示当前桶 `currentBucket.signals`：每条 signal 渲染为卡片（title + description + 利好/利空标签）
- **命中提示**：当回放推进到某桶且该桶有 signals 时，用 antd `notification` 或 `message` 弹出提示（仿策略中心命中动效）；同时在面板累积展示当日所有已命中策略
- 顶部展示当日策略命中统计（利好 X 条 / 利空 Y 条）

### 6. 底部吸底进度条 `ReplayProgressBar`

- 固定定位 `position: fixed; bottom: 0`，遮罩底部 56px
- 左侧：`◀倒推`（stepBackward）、`▶/⏸`（toggle）、`快进▶`（stepForward）
- 中间：`<Slider>`（antd），min=0, max=timeBuckets.length-1，value=currentIndex，onChange=seek；拖拽时暂停自动播放
- 右侧：当前桶 `displayTime` / 末桶 displayTime（如 `09:35 / 15:00`）
- 进度条上方细条显示各桶策略命中标记（红/绿小点），可视化策略分布

## 回放时间桶与节奏

- **时钟基准**：fundSnapshot 5min 桶（9:35, 9:40, ... 11:30, 13:05, ... 15:00）
- **自动播放**：每 5000ms 推进一个桶，到末桶（15:00）自动暂停
- **手动**：快进/倒推 = ±1 桶；拖拽 = 跳转到任意桶；拖拽期间暂停自动播放，松手后不自动恢复（需手动点播放）
- **暂停**：清除定时器，保留 currentIndex
- **切换日期**：重置 currentIndex=0，isPlaying=false，重新拉取 data

## 验证方式

1. **后端**：重启 server，`curl http://localhost:<port>/training_camp/dates` 返回日期数组；`curl /training_camp/data?date=20260821` 返回 timeBuckets 结构，验证 fundFlow/volume/indexTline/stockChanges/signals 字段齐全
2. **前端**：`npm run dev` 启动，左侧菜单点"训练营"，选择 20260821，验证：
   - 左侧各模块按桶更新（资金折线逐步增长、个股异动随桶变化、涨跌幅前十随桶重排）
   - 分区/合并tab无资金净流入字段、无研报tab
   - 叠加分时可回放历史分时
   - 右侧策略面板在命中的桶弹出策略卡片
   - 底部进度条拖拽/快进/倒推/暂停均生效
3. **分组**：新建分组、选日期、保存，刷新页面后分组仍在；删除分组生效
