# 快进快出类：资金净流入阈值抬高态时改「板块内选股」

## Context

快进快出类策略已有规则：连续 2 笔已完结交易的折算收益率 ≤ 3% → 买点诊断资金净流入阈值由 20 亿提高到 30 亿，且首次建仓强制只买半仓。用户希望在此「抬高态」下再叠加一条选股约束：

- 不再从**全量自选股**中挑 N 日涨幅最大的个股；
- 改为在 `key_blocks` 页面「中性 + 进攻」tag 板块中，按**买点触发时点的板块分时涨幅**排名，从第 1 名开始依次找**第一个与全量自选股中的科技股有重叠**的板块；
- 在该板块与自选科技股的交集内，仍按 N 日涨幅最大选股；
- 第 1 名没有重叠就取第 2 名，以此类推。

范围：**仅回测**（`/backtest` 页面路径），线上实盘买点推荐不改。

已确认口径：中性 + 进攻（页面无「科技」tag），见 `constant/block_code.js` 的 tag 字段。

## 改动清单

### 1. `server/src/service/buySellBacktest/constants.js`

新增并导出：

```js
// 快进快出类「资金净流入阈值抬高态」板块内选股（2026-10-23 用户新增）：
// 抬高态下只在 tag 为「中性」/「进攻」的板块中，按买点时刻板块分时涨幅从高到低，
// 取第一个与全量自选科技股有重叠的板块，再在其交集内选 N 日涨幅最大者
const EMO_QUICK_RAISED_BLOCK_TAGS = ['中性', '进攻'];
```

### 2. 新建 `server/src/service/buySellBacktest/engine/quickRaisedBlock.js`

```js
resolveQuickRaisedBlock(bucket, dateStr) => null | {
  blockName, tag, avgChange, rank, codes: Set<string>, memberCount
}
```

实现要点：
- `getSimContext()` 非空时直接返回 `null`（随机模拟注入的合成股不在板块配置里，保持原有模拟口径）。
- `bucket.blockRanking.all` 为空 → `null`。
- 按 `tagMap.get(blockName)` ∈ `EMO_QUICK_RAISED_BLOCK_TAGS` 过滤；`all` 本身已按 avgChange 降序，按数组顺序即排名（`rank = index + 1`，仅统计符合条件的板块）。
- 自选科技股集合：`getMonitorStocks()` 中 `isTech !== false`、`!EXCLUDED_CODES.has(code)`，用 mtime 缓存（参考 `pickHelpers.getNonTechWatchlistCodeSet` 的写法），不要每次读盘。
- 逐板块取交集时，每个成分股需同时满足：`isStockInWatchlistAt(code, dateStr, minute)`（买点时刻已在自选股）、存在于 `bucket.stockChanges` 且 `lastPx > 0`。
- 返回第一个交集非空的板块；全部板块都无交集 → `null`（此时**回退原逻辑**：仍从全量自选股选 N 日涨幅最大，不加板块限制）。
- 通过 `require('../deps')` 取 `getMonitorStocks / isStockInWatchlistAt / getSimContext / getKeyBlockConstituents / getKeyBlockTagMap`，避免与 service 层形成环。

### 3. `engine/selectors/delegates.js`

快进快出系列把选股委托给 `highest_{N}d_gain` 时，目前 `restrictCodes` 硬编码传 `null`，会丢掉新限制。两处递归调用：
- `ctx` 解构增加 `restrictCodes`；
- 第 39 行、第 74 行调用末尾把 `null` 改为 `restrictCodes`（`emoQuickTie` 仍保持 `true`）。

`pickBest.js` 本身**不需要修改**（沿用已有 `restrictCodes`）。

### 4. 三处建仓分支（抬高态下把板块交集作为候选池）

共同模式（在 `pickBestStock(...)` **之前**计算 `gateRaised`，替换原先在选股之后才定义的位置）：

```js
const gateRaised = fundGate != null && fundGate.isRaised();   // multi: st.fundGate
const raisedBlock = emoQuickHalfBuy && gateRaised
  ? resolveQuickRaisedBlock(bucket, dateStr)
  : null;
const picked = pickBestStock(..., emoCycSet, raisedBlock ? raisedBlock.codes : null);
if (picked && raisedBlock) picked.raisedBlockInfo = raisedBlock;
```
